# Embedded Systems Basic to Advanced Diploma — IMT School

## Credential Details
- **Recipient**: Yousef Alsayed Abdelfatah Abo Elkhear (Yousef Alsayed Abdelfattah)
- **Institution**: IMT School

- **Date Completed**: March 11, 2023

## Comprehensive Syllabus & Technical Mastery
- **C Programming for Embedded Systems**: Memory organization (stack, heap, code, data, BSS), bitwise operations, volatile keywords, register manipulation, pointers, and MISRA-C rules.
- **Microchip ATmega32 Architecture**: Internal architecture, memory maps, system clocking, and register layouts.
- **Peripheral Driver Development from Scratch**:
  - **DIO (Digital Input/Output)**: Pin direction and state configuration.
  - **External Interrupts (EXTI)**: Edge-triggered interrupt handling and ISR design.
  - **Timers & Counters**: Normal mode, CTC mode, Fast PWM, and Phase Correct PWM generation for motor control.
  - **Analog-to-Digital Converter (ADC)**: Single conversion, auto-triggered conversion, and interrupt-driven sampling.
- **Communication Protocols**:
  - **USART**: Asynchronous serial communication for telemetry and debugging.
  - **SPI**: High-speed synchronous master/slave communication.
  - **I2C / TWI**: Two-wire multi-device bus communication for EEPROMs and sensors.
- **Real-World Hardware Interfacing**: Character LCDs (4-bit & 8-bit modes), 4x4 keypad matrices, 7-segment displays, DC motor H-Bridges (L298N), and stepper motors.
