## Core Technical Foundations
- **Transformer Architecture & Mechanics**: Attention mechanisms, tokenizer subtleties, embeddings, and context handling.
- **Retrieval-Augmented Generation (RAG)**: Chunking strategies (fixed, semantic, hierarchical), embedding models, vector indexing (HNSW), cosine similarity, and grounded prompt synthesis.
- **QLoRA Fine-Tuning**: Quantized Low-Rank Adaptation (4-bit NF4 quantization) with `bitsandbytes`, Hugging Face `peft`, and `transformers`, enabling fine-tuning of open-source models (Llama, Mistral) on consumer GPUs.
- **LangChain & Agents**: ReAct loops, prompt templates, structured output parsing, tools, and memory managers.
