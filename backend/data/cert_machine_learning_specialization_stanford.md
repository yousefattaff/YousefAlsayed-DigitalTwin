## Three Rigorous Specialization Courses
### 1. Supervised Machine Learning: Regression and Classification
- Linear regression with multiple input variables, cost functions (Mean Squared Error), gradient descent vectorization.
- Logistic regression, decision boundaries, cost function with cross-entropy, overfitting solutions, and L2 regularization.

### 2. Advanced Learning Algorithms
- Multi-layer perceptrons, forward propagation vectorization in NumPy and TensorFlow.
- Activation functions (ReLU, Sigmoid, Softmax), multi-class classification, and loss backpropagation.
- Decision trees, random forests, and boosted trees (XGBoost).
- Diagnostic workflows: bias vs. variance analysis, learning curves, and model debugging.

### 3. Unsupervised Learning, Recommenders & Reinforcement Learning
- Unsupervised learning: K-Means clustering, PCA dimensionality reduction, and anomaly detection using Gaussian distributions.
- Collaborative filtering and content-based recommender systems (matrix factorization, neural network embeddings).
- Reinforcement Learning: Markov Decision Processes (MDP), state-action values (Q-function), Deep Q-Networks (DQN), and Bellman equations.
