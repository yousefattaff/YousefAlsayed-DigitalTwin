- **Scope**: Rigorous completion of all lectures, problem sets, and **twelve comprehensive AI engineering projects**.

## Projects & Core Technical Disciplines
1. **Search**: Depth-First Search (DFS), Breadth-First Search (BFS), A* Search with heuristics, Minimax adversarial search with Alpha-Beta Pruning (Tic-Tac-Toe AI).
2. **Knowledge**: Propositional logic, inference rules, model checking, resolution, and constraint satisfaction problems (Sudoku, Knights and Knaves).
3. **Uncertainty**: Probability theory, conditional probability, Bayesian Networks, Markov Models, and Hidden Markov Models (HMM).
4. **Optimization**: Local search, Hill Climbing, Simulated Annealing, Linear Programming.
5. **Machine Learning**: Nearest-Neighbor classification, Linear Regression, Support Vector Machines (SVM), K-Means clustering.
6. **Neural Networks**: Artificial neural networks, feedforward architectures, backpropagation, Convolutional Neural Networks (CNN) for image recognition.
7. **Language**: Natural language processing, tokenization, n-gram models, TF-IDF, Word2Vec, parsing context-free grammars, and sentiment analysis.
