## Comprehensive Computer Science Foundation
- **Algorithmic Thinking & Complexity**: Asymptotic notation (Big O, Big Omega, Big Theta), sorting algorithms (Selection, Bubble, Merge Sort), searching (Linear, Binary).
- **Low-Level C Programming**: Manual memory management with `malloc` and `free`, pointer arithmetic, segmentation fault debugging, buffer overflow mechanics.
- **Data Structures**: Implementation from scratch of dynamic arrays, singly and doubly linked lists, hash tables, tries, and binary search trees.
- **High-Level Languages**: Python programming, object-oriented concepts, and standard library data structures.
- **Relational Databases & SQL**: Schema design, normalization, complex relational queries, joins, and indexing.
- **Full-Stack Web Technologies**: HTML5, CSS3, JavaScript, Flask backends, HTTP request/response lifecycles, and REST APIs.
- **Cybersecurity Fundamentals**: Hashing algorithms, encryption, SQL injection vulnerabilities, and cross-site scripting (XSS) defenses.
