## Production Engineering Curriculum
- **Scalable Serving**: Deploying high-concurrency LLM backends with FastAPI, asynchronous task queues, and streaming SSE responses.
- **Docker & Container Orchestration**: Multi-stage Docker builds, containerizing LLM runtime dependencies, and minimizing production image size.
- **Cost Reduction Strategies**: Semantic caching, prompt compression, token throttling, and multi-tier model cascading (routing simple tasks to light models and complex reasoning to frontier models).
- **Evaluation & Telemetry in Production**: Setting up OpenTelemetry traces, latency dashboards, rate-limit backoff handling, and automated output guardrails.
