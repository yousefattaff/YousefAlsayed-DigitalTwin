# AI Engineering Mastery — Yousef Alsayed Abdelfattah

Yousef Alsayed possesses a comprehensive, production-tested AI engineering skillset spanning foundational machine learning algorithms to cutting-edge autonomous agent frameworks and high-throughput LLM deployment pipelines.

## 1. Large Language Model (LLM) Engineering & Retrieval-Augmented Generation (RAG)
- **Advanced RAG Pipelines**: Semantic chunking, dense vector embeddings, hybrid search combining BM25 keyword matching with dense vector retrieval, cross-encoder re-ranking, and context window optimization.
- **Vector Stores & Database Integration**: ChromaDB, Pinecone, DynamoDB Streams with GSI index querying, and pgvector.
- **Model Fine-Tuning & Quantization**: Parameter-Efficient Fine-Tuning (PEFT), Low-Rank Adaptation (LoRA), and QLoRA 4-bit/8-bit quantization on Hugging Face transformers.
- **Evaluation & Alignment**: Proven RLHF evaluation experience (50+ daily evaluations across 6+ technical domains at Outlier), prompt injection mitigation, deterministic guardrails, and hallucination reduction.

## 2. Autonomous Agents & Model Context Protocol (MCP)
- **Agent Frameworks**: LangChain, LangGraph stateful multi-agent workflows, CrewAI, AutoGen, and custom loop architectures.
- **Model Context Protocol (FastMCP)**: Building stdio and SSE MCP servers connecting LLMs securely to local filesystems, live database streams, web scrapers, and external APIs.
- **Automated Coding Agents**: Claude Code workflows, AI Coder paradigms, test-driven code refactoring, and AST-aware codebase analysis.
- **No-Code / Low-Code Agentic Workflows**: High-complexity workflow automation with **n8n**, integrating webhook triggers, multi-step routing, and voice agent telephony.

## 3. High-Scale Production Engineering & Cost Optimization
- **Low-Latency Inference**: Orchestrating sub-second inference using Groq LPU hardware, vLLM, and OpenAI-compatible endpoints.
- **Deterministic 6-Stage Cost-Skip Ladder**: An architectural pattern pioneered at Arche Robotics to pre-screen telemetry deterministic rules before making costly LLM calls, achieving massive cost reduction.
- **Containerization & Cloud Infrastructure**: Dockerized microservices, AWS Lambda serverless execution, AWS SAM deployment templates, and Vercel edge runtime integration.
