# Project Media Assets

This folder is designated for your project screenshots and video demonstrations.

### Supported Files & Formats
- **Screenshots:** `.png`, `.jpg`, `.webp` (Recommended resolution: 1200x675 or 16:9 aspect ratio)
- **Videos:** `.mp4`, `.webm` (Auto-plays on card hover, muted by default)
