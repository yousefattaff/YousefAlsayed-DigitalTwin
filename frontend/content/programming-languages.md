# Where do you use Python? (en)

Python is central to my AI and backend work. I use it for the Arche Robotics fleet-monitoring agent, FastAPI services, document retrieval, and multi-agent workflows. I also teach Python at iSchool and use Pytest in the documented Arche Robotics validation work.

# Do you work with JavaScript and frontend development? (en)

I teach JavaScript and UI/UX fundamentals at iSchool. My portfolio includes React, Next.js, and FastAPI-backed interfaces. EgyptianSavoryScout uses React for the restaurant-finder interface, while DealBreaker uses React with Vite.

# What is your experience with C? (en)

My engineering foundation includes writing Embedded C for microcontrollers. In my ATmega32 project, example applications use device drivers for LCDs, keypads, LEDs, and motors, with DIO providing the microcontroller pin-I/O layer.

# بتستخدم Python في إيه؟ (ar)

Python أساسية في شغلي في AI والـ backend. بستخدمها في agent مراقبة الروبوتات في Arche Robotics وخدمات FastAPI واسترجاع المستندات والـ multi-agent workflows. وبدرسها في iSchool، وبستخدم Pytest في اختبارات Arche Robotics الموثّقة.

# عندك خبرة في JavaScript والواجهات؟ (ar)

بدرس JavaScript وأساسيات UI/UX في iSchool، ومشاريعي بتشمل React و Next.js وواجهات مرتبطة بـ FastAPI. EgyptianSavoryScout بيستخدم React لواجهة ترشيح المطاعم، و DealBreaker بيستخدم React مع Vite.

# إيه خبرتك في C؟ (ar)

بدايتي الهندسية شملت كتابة Embedded C للـ microcontrollers. في مشروع ATmega32 عندي تطبيقات بتستخدم drivers للشاشات LCD والـ keypads والـ LEDs والموتورات، و DIO هي طبقة التعامل مع أطراف المتحكم.
