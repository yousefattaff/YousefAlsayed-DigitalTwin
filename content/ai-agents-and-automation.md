# Which agent frameworks do you work with? (en)

My agent and automation toolkit includes the OpenAI Agents SDK, CrewAI, LangGraph, n8n, MCP, and FastMCP. My learning and side projects focus on practical agent workflows, tool integration, and automation. At Arche Robotics, I apply MCP tooling to the robot-monitoring workflow.

# What have you built with CrewAI? (en)

My Advanced Engineering Team uses four CrewAI agents. A lead creates the design, a backend agent writes Python and can run it in Docker, a frontend agent builds a Gradio demo, and QA writes tests and can run them in Docker.

# What have you built with the OpenAI Agents SDK? (en)

My SDR Multi-Agent project uses the OpenAI Agents SDK for a B2B sales workflow. It researches a company with three parallel Tavily searches, writes professional, witty, and concise email drafts, and sends the manager's selected draft through SendGrid.

# بتشتغل بأدوات agents إيه؟ (ar)

أدواتي تشمل OpenAI Agents SDK و CrewAI و LangGraph و n8n و MCP و FastMCP. تعلّمي ومشاريعي بيركزوا على workflows عملية وربط الأدوات والأتمتة. وفي Arche Robotics بستخدم أدوات MCP ضمن شغل مراقبة الروبوتات.

# بنيت إيه بـ CrewAI؟ (ar)

مشروع Advanced Engineering Team بيستخدم أربعة agents في CrewAI. الـ lead بيعمل التصميم، والـ backend بيكتب Python ويقدر يشغّلها في Docker، والـ frontend بيبني Gradio demo، والـ QA بيكتب الاختبارات ويقدر يشغّلها في Docker.

# بنيت إيه بـ OpenAI Agents SDK؟ (ar)

مشروع SDR Multi-Agent بيستخدم OpenAI Agents SDK في workflow مبيعات B2B. بيبحث عن شركة بثلاث عمليات Tavily متوازية، ويكتب رسائل بأسلوب professional و witty و concise، وبعد اختيار المدير بيتبعت الإيميل عن طريق SendGrid.
