# What backend and cloud tools do you use? (en)

I build Python backends with FastAPI and use Docker to package applications. At Arche Robotics, my serverless fleet-monitoring work uses AWS Lambda, AWS SAM, and DynamoDB Streams. My broader portfolio includes S3, API Gateway, and CloudFront.

# How do you make AI outputs traceable? (en)

My toolkit includes Pydantic for structured outputs and Langfuse for tracing. Advanced Engineering Team includes optional Langfuse tracing, enabled when its required configuration is present. My Outlier experience also involved evaluating LLM outputs and investigating reasoning and hallucination issues.

# How have you used Docker in agent applications? (en)

In Advanced Engineering Team, the backend and QA agents can run generated Python and tests in Docker. The project combines CrewAI orchestration, Groq models, a Gradio interface, and optional Langfuse tracing.

# بتستخدم أدوات backend وسحابة إيه؟ (ar)

ببني Python backends باستخدام FastAPI، وبستخدم Docker لتجهيز التطبيقات. في Arche Robotics شغل fleet monitoring بيعتمد على AWS Lambda و AWS SAM و DynamoDB Streams. مشاريعي وخبرتي كمان تشمل S3 و API Gateway و CloudFront.

# بتتابع مخرجات أنظمة AI إزاي؟ (ar)

أدواتي تشمل Pydantic للمخرجات المنظمة و Langfuse للتتبع. Advanced Engineering Team فيه تتبع اختياري باستخدام Langfuse عند توفير الإعدادات المطلوبة. وخبرتي في Outlier شملت تقييم إجابات LLMs وفحص مشاكل الاستدلال والهلوسة.

# استخدمت Docker مع الـ agents إزاي؟ (ar)

في Advanced Engineering Team، الـ backend والـ QA agents يقدروا يشغّلوا Python والاختبارات داخل Docker. المشروع بيجمع CrewAI وموديلات Groq وواجهة Gradio وتتبع اختياري باستخدام Langfuse.
