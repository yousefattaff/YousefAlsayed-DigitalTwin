# What topics have you been learning and exploring? (en)

My learning and side projects include multi-agent workflows with the OpenAI Agents SDK, CrewAI, LangGraph, and n8n; document retrieval with LangChain and ChromaDB; and smaller local Qwen model fine-tuning with QLoRA. I also work with FastAPI, Pydantic, Langfuse, and Docker to build and package applications.
